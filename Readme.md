# PhotoAlbum 電子相簿

一款專為 Android 手機與平板打造的桌面數位相框與本地電子相簿應用程式，採用 Kotlin 與 Jetpack Compose 開發。

## 主要功能

* **全向自動旋轉與防休眠輪播**：進入全螢幕或幻燈片播放時保持螢幕恆亮，支援直向、左橫向、右橫向與倒置四向感應器自動旋轉，並保留目前播放進度。
* **無閃黑平滑過渡**：採用淡入淡出轉場效果，照片切換自然流暢不閃黑。
* **直覺手勢操作**：支援上下左右滑動翻頁、單擊切換控制列顯示、長按返回主網格頁面。
* **即時相簿媒體庫同步**：自動監聽本機媒體庫變動與資料夾階層，新增照片即時更新顯示。
* **即時電量顯示**：輪播畫面右上角常駐顯示電池電量與充電狀態，方便長期作為桌面相框使用。
* **GitHub 線上檢查與更新**：內建檢查 GitHub Releases 最新版本功能，可一鍵下載並安裝新版 APK。

## 版本更新紀錄 (Changelog)
### v1.1.3
* **新增** 加入一般電子相簿經典的 Ken Burns 緩慢縮放平移運鏡與 800ms 交叉淡入淡出轉場特效。
* **優化** 輪播檢視時單擊螢幕即可一鍵隱藏或顯示所有懸浮介面（包含日期時間、電量與提示列）。
* **新增** 宣告並於啟動時自動請求儲存與媒體圖片讀取權限，確保新安裝後即可直接讀取相簿資料夾。


### v1.1.2
* **修復** 重構全螢幕輪播切換邏輯改用 `Crossfade` 交叉淡入淡出，並限制單張圖片最大解碼尺寸（1920x1920），徹底解決連續輪播時張數跳動但畫面卡在同一張的問題。
* **優化** 將計時延遲改用 Kotlin `Duration`（`1.seconds`）寫法，消除編譯器棄用警告。

### v1.1.1
* **建置** 升級為正式 Release 簽章憑證打包（`assembleRelease`），固定開發者憑證指紋以支援未來無縫覆蓋更新。

### v1.1
* **優化** 採用雙層前景淡入與圖片預載架構，徹底消除輪播切換時的黑邊與閃爍。
* **新增** 輪播畫面左上角顯示即時日期、時間與秒數（`yyyy/MM/dd HH:mm:ss`）。
* **新增** 自動記憶上次輪播與檢視照片位置，重新開啟輪播時無縫接續播放。
* **變更** 應用程式名稱改為繁體中文「電子相簿」。
* **重構** 將媒體庫讀取、線上更新、輪播介面與主畫面拆分為獨立模組檔案。
* **自動化** GitHub Actions 發布 Release 時自動擷取 `Readme.md` 對應版本的更新說明。

### v1.0.1
* **新增** 輪播無閃黑淡入淡出過渡效果（Crossfade）。
* **新增** 輪播全螢幕手勢操作：上下左右滑動切換上／下一張、單擊切換狀態列、長按返回主頁面。
* **新增** 全螢幕與輪播模式下支援感應器四向自動旋轉，並於旋轉時保留目前播放進度不跳出。
* **新增** 輪播畫面右上角即時電池電量百分比與充電狀態顯示。
* **新增** 設定面板內建 GitHub Releases 線上檢查更新與自動下載安裝 APK 功能。
* **優化** 加入系統相簿變動監聽（ContentObserver）與主動掃描機制，新增圖片即時自動刷新。

### v1.0.0
* **初始發布** 支援本機相簿網格檢視、多層子資料夾篩選、幻燈片自動輪播間隔設定、螢幕恆亮開關、深／淺色主題切換與本機設定自動記憶。
* **建置** 整合 GitHub Actions 雲端自動編譯打包與 Release 發布流程。
