# PhotoAlbum 電子相簿

把閒置的 Android 手機或平板，變成好看又實用的桌面數位相框。

# 這款 App 可以做什麼？

* **照片自動輪播**：支援平滑淡入淡出與緩慢縮放運鏡，照片切換自然流暢、不會閃黑屏。
* **桌面時鐘與電量顯示**：輪播時畫面角落會顯示即時日期、時間（含秒數）與電池電量，放桌上當電子時鐘或相框剛剛好。
* **相簿即時更新**：手機或平板新增、刪除照片時，相簿畫面會自動同步，不用手動重開。
* **直覺手勢操作**：左右滑動切換照片、點一下畫面隱藏或顯示時間與電量、長按返回相簿總覽。
* **自動旋轉與螢幕恆亮**：播放時螢幕不會自動休眠，直放、橫放都能自動轉向，並記住上次看到哪一張。
* **繁體中文／英文切換**：支援中英文介面，在設定裡點一下就能即時切換。
* **一鍵檢查更新**：不用手動重抓安裝檔，在 App 設定裡就能直接檢查並更新到最新版。

# 怎麼下載與安裝？

1. 點進本頁面的 **[Releases（版本發布）](https://github.com/Henryliu880922/PhotoAlbum/releases)**。
2. 下載最新版本的 `.apk` 檔案（例如 `PhotoAlbum-v1.1.4-b10.apk`）。
3. 在手機或平板上點擊安裝（若系統提示，請允許「安裝未知應用程式」）。
4. 以後有新版本時，直接打開 App 的 **設定 > 關於與更新** 就能線上更新，原本的設定都會保留。

# 設備需求

* **適用裝置**：Android 手機、平板（非常適合拿舊平板或備用機當作桌面相框）
* **系統版本**：Android 8.0 以上
* **硬體空間**：安裝檔只要約 10 MB，記憶體 2 GB 以上的舊機也能順暢播放
* **權限說明**：
  * **讀取相片**：用來讀取你裝置裡的照片進行輪播。
  * **網路連線**：只有你手動點「檢查更新」時才會用到，平常播放照片完全離線、不耗流量。
