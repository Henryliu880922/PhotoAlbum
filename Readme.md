# PhotoAlbum 電子相簿

一款專為 Android 手機與平板打造的桌面數位相框與本地電子相簿應用程式，採用 Kotlin 與 Jetpack Compose 開發。內建繁體中文與英文雙語介面，支援無縫自動輪播、資料夾篩選與線上更新。

## 主要功能

* **即時零黑屏雙語切換**：完整支援**繁體中文 (zh-TW)** 與 **English** 雙語介面，可跟隨系統或於設定面板內即時切換，切換過程零黑屏、不中斷目前操作。
* **全向自動旋轉與防休眠輪播**：進入全螢幕或幻燈片播放時保持螢幕恆亮，支援直向、左橫向、右橫向與倒置四向感應器自動旋轉，並保留目前播放進度。
* **無閃黑平滑過渡**：採用淡入淡出轉場效果與 Ken Burns 緩慢縮放平移運鏡，照片切換自然流暢不閃黑。
* **直覺手勢操作**：支援上下左右滑動翻頁、單擊切換控制列顯示、長按返回主網格頁面。
* **即時相簿媒體庫同步**：自動監聽本機媒體庫變動與資料夾階層，新增照片即時更新顯示。
* **即時時間與電量顯示**：輪播畫面常駐顯示日期時間（含秒數）與電池電量充電狀態，方便長期作為桌面相框使用。
* **GitHub 線上檢查與更新**：內建檢查 GitHub Releases 最新版本功能，可一鍵下載並安裝新版 APK。

## 使用需求與裝置建議

* **支援設備：** Android 手機、平板電腦（非常適合拿舊平板或備用機當作桌面電子相框使用）
* **系統版本：** Android 8.0 或更新版本（近 7～8 年內的 Android 裝置幾乎都能安裝）
* **硬體規格：** 記憶體（RAM）2 GB 以上即可順暢播放，程式會自動最佳化高畫質照片，老舊平板也不易卡頓或閃退
* **所需空間：** 安裝檔僅約 10 MB，其餘空間用來存放您的照片即可
* **需要開放的權限：**
  * **讀取相片與檔案權限：** 讓相簿能夠讀取您手機或平板裡的照片資料夾進行輪播
  * **網路連線權限：** 僅在您點擊「檢查新版本」時用來下載更新檔，平時播放照片完全不需要網路，離線也能正常使用
