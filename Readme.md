# PhotoAlbum 電子相簿

一款使用 **Kotlin** 與 **Jetpack Compose** 開發的原生 Android 電子相簿應用程式，支援多層資料夾穿透讀取、全螢幕幻燈片自動輪播與本機設定持久化記憶。

## 主要功能

- **多層資料夾穿透篩選**：自動掃描裝置內的相片目錄與上層母資料夾，可選擇顯示「全部資料夾」或指定單一分類（包含底下所有子資料夾的照片）。
- **全螢幕幻燈片輪播**：支援一鍵啟動全螢幕自動播放，可自訂切換間隔（3 秒 / 5 秒 / 10 秒 / 30 秒）。
- **桌面相框恆亮模式**：檢視大圖或輪播期間自動保持螢幕恆亮，關閉檢視時自動恢復系統休眠設定。
- **彈性版面與排序**：支援 2 欄 / 3 欄 / 4 欄網格切換，以及「最新優先 / 最舊優先」排序。
- **外觀主題與設定記憶**：支援跟隨系統、淺色模式與深色模式，所有偏好設定透過 `SharedPreferences` 自動儲存。
- **跨版本權限相容**：完整支援 Android 8.0 (API 26) 至 Android 14+ 的媒體讀取權限機制。

## 技術架構

- **語言**：Kotlin
- **UI 框架**：Jetpack Compose (Material 3)
- **圖片載入**：Coil (`coil-compose`)
- **最低支援版本**：Android 8.0 (API 26) / 目標版本 API 36
- **自動化建置**：透過 GitHub Actions 自動編譯並發布對應版號的 APK 至 Releases

## 安裝方式

1. 前往本倉庫右側的 **Releases** 頁面。
2. 下載最新版本的 `PhotoAlbum-vX.X.X.apk`。
3. 在 Android 裝置上開啟檔案並允許安裝來源不明的應用程式即可使用。
